# Norma de representación de los planos (estudiada del modelo del usuario)

| elemento | cómo se dibuja |
|---|---|
| Muro cortado | blanco con trama punteada fina entre dos líneas negras (0,8); esquinas en inglete; pilares y muros cortos macizos |
| Muro portante deducido | igual que el cortado, con su eje (trazo y punto, burbuja) |
| Tabique | doble línea fina (0,4), sin relleno |
| Hueco | el muro se interrumpe; jambas cerradas; carpintería en doble línea fina, vidrio en línea media, vierteaguas exterior |
| Puerta | hoja (0,8) y arco de barrido fino (0,35) hacia la estancia |
| Lo que queda debajo del corte | línea fina, vectorial, con líneas ocultas (sin raster) |
| Lo que queda encima | discontinua fina (vuelos, cuerpos superiores) |
| Mobiliario | gris fino (0,3–0,35) |
| Cotas exteriores | cadenas paralelas a cada fachada: parciales (huecos, muros, pilares) y totales; trazo oblicuo y número pequeño |
| Cotas interiores | ancho y fondo de cada estancia, dentro de ella |
| Estancias | nombre y superficie real (del polígono), sin salirse del interior |
| Lucernarios | base y aristas de la pirámide; vidrio en gris azulado claro |
| Interiores | solo en planos; deben dar lógica a lo conocido (logia, pilares, huecos, escalera), nunca superponerse |
| Exterior | no se inventa: solo lo que se ve en las fotos |
